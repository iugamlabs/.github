# 参与 iugam / Contributing to iugam

## 中文

请先在具体工具仓库阅读 README、开发约定和已有 Issues。报告问题时附上系统、工具版本、复现步骤、预期与实际结果；不要提交密码、Token 或私人数据。

工具问题请提交到对应仓库；品牌、主页和项目目录建议可提交到[本仓库 Issues](https://github.com/iugamlabs/.github/issues)。修改项目目录后运行 `scripts/render-profile.py`，并同时维护中英描述。

Fork 项目的贡献请遵守该仓库的上游归属及合并指南。

## English

Read the target project's README, development instructions and existing issues first. Include your operating system, tool version, reproduction steps, expected behavior and actual behavior in bug reports. Do not submit passwords, tokens or private data.

Report tool-specific issues in the relevant repository. Send brand, profile and catalog suggestions to [this repository's issues](https://github.com/iugamlabs/.github/issues). After editing the catalog, run `scripts/render-profile.py` and maintain both Chinese and English descriptions.

For forked projects, follow the repository's upstream attribution and merge guidance.
