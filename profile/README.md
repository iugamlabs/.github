# iugam

[中文](https://github.com/iugamlabs/.github/blob/master/profile/README.md) · [English](https://github.com/iugamlabs/.github/blob/master/profile/README.en.md)

![iugam](https://raw.githubusercontent.com/iugamlabs/.github/master/brand/wordmark.svg)

实用、轻量的开发者与效率工具。

iugam 是一个独立开发品牌，名称来自潮州话中的油柑。我们构建解决具体问题的工具，也保留对新想法的探索。GitHub 账号为 **iugamlabs**。

## 精选工具

| 项目 | 用途 |
| --- | --- |
| [ship](https://github.com/iugamlabs/ship) | 单文件 CLI：构建、推送与远程部署，支持健康检查及回滚。 |
| [code-porter](https://github.com/iugamlabs/code-porter) | 以 Git 为核心的工作区扫描、导出与迁移工具。 |
| [sharp-ico](https://github.com/iugamlabs/sharp-ico) | 纯 C# 图标工具，将 PNG 转为多尺寸 Windows ICO，并验证图层。 |
| [image-glider](https://github.com/iugamlabs/image-glider) | 跨平台批量图像转换工具，支持 .NET AOT 分发。 |
| [pdf-toc-extractor](https://github.com/iugamlabs/pdf-toc-extractor) | 提取 PDF 目录，支持多种输出格式。 |
| [aiquokka](https://github.com/iugamlabs/aiquokka) | AI 订阅额度监控；独立维护的 Fork，保留上游来源。 [上游](https://github.com/McKean/aiquokka) |

## 安装

```bash
brew tap iugamlabs/tap
brew install ship
```

```powershell
scoop bucket add iugam https://github.com/iugamlabs/scoop
scoop install ship
```

各工具支持的平台和其他安装方式请查阅项目 README。

## 项目目录

### 工具

- [ship](https://github.com/iugamlabs/ship) — 单文件 CLI：构建、推送与远程部署，支持健康检查及回滚。
- [code-porter](https://github.com/iugamlabs/code-porter) — 以 Git 为核心的工作区扫描、导出与迁移工具。
- [sharp-ico](https://github.com/iugamlabs/sharp-ico) — 纯 C# 图标工具，将 PNG 转为多尺寸 Windows ICO，并验证图层。
- [image-glider](https://github.com/iugamlabs/image-glider) — 跨平台批量图像转换工具，支持 .NET AOT 分发。
- [pdf-toc-extractor](https://github.com/iugamlabs/pdf-toc-extractor) — 提取 PDF 目录，支持多种输出格式。
- [code-packager](https://github.com/iugamlabs/code-packager) — 按忽略规则打包代码，排除不必要的文件。
- [swag-cli](https://github.com/iugamlabs/swag-cli) — 管理 LinuxServer.io SWAG 的命令行工具。
- [uv-lens](https://github.com/iugamlabs/uv-lens) — 检查 Python 依赖的新版本，生成 uv 升级建议。
- [wechat-clone](https://github.com/iugamlabs/wechat-clone) — macOS 微信分身管理工具。
- [org-readme-gen](https://github.com/iugamlabs/org-readme-gen) — 根据受众生成组织主页，区分公开与内部内容。
- [wechatctl](https://github.com/iugamlabs/wechatctl) — Linux 微信实例管理与本地数据工具。
- [wpk](https://github.com/iugamlabs/wpk) — Windows 软件查询、定位与升级工具。

### Fork 与实验

- [aiquokka](https://github.com/iugamlabs/aiquokka) — AI 订阅额度监控；独立维护的 Fork，保留上游来源。 [上游](https://github.com/McKean/aiquokka)
- [go-oa](https://github.com/iugamlabs/go-oa) — 基于上游项目维护的 OA 管理系统 Fork。 [上游](https://github.com/lock-upme/OPMS)
- [today-tv-django](https://github.com/iugamlabs/today-tv-django) — 基于 DjangoStarter 的 today-tv 后端 Fork。 [上游](https://github.com/djangostarter/web)
- [sonar](https://github.com/iugamlabs/sonar) — 检查与管理本地端口服务的 CLI Fork。 [上游](https://github.com/raskrebs/sonar)
- [agent-wechat](https://github.com/iugamlabs/agent-wechat) — 基于 RPA 的微信自动化 Fork。 [上游](https://github.com/thisnick/agent-wechat)

### 分发与社区
